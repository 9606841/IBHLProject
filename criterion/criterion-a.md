# Criterion A
## Problem
In the modern day, those with busy careers and academics rely on software applications to handle tedious planning efforts in their schedule. However, too often these applications come with two primary deficiencies: lack of personalization and lack of connectivity between applications. Each user utilizes a unique workflow, and very few applications allow for customization in their UIX. Furthermore, schedules, task organizers, calendars, and health tracking applications are all separate, and users need to input individual tasks multiple times on different applications in different ways, leading to an increased level of friction in the overarching UIX. In addition, few applications allow for an easy integration of work-life balance as the inputted data is often only compatible with tasks to be finished rather than personal goals and trackers. Adding these features would allow busy individuals to organize their lives in a simplified, personalized, and holistic manner.

This problem provides an interesting outlook as it attempts to build an application that has a UIX specific to each user rather than having one set, default UIX. This not only allows the user to personalize their planner, but it allows them to include and exclude feature based on their workflow so the need for multiple applications is mitigated and the user experience is far more streamlined and basic. However, in order for this to be an effective solution, the features that users can add should be easily flexible while maintaining a base level of functionality that any user can utilize.

In addition, the solution should be usable through a web based browser and function with accounts and logic capabilities. This allows the application to be used effectively by many users as the majority of currently popular digital planners are housed in a browser. Ensuring these capabilities not only allows users to have individual UIX in an effective manner, but it decreases the friction from shifting from one(or multiple) planning systems into the solution application.

## Criterion
1. The planner application must have customizable arrangements between different features, allowing user to adjust the layout to their preference.
2. The planner application must be customizable within each features, allowing the user to adjust what each feature consists of.
3. The planner application must include multiple features distinctive to planner applications, including task tables, Kanban boards, and calendars.
4. The planner application must include features relating to personal goals, including sleep trackers, meal trackers, and personal goal trackers
5. The planner application must have capabilities to function with common keyboard shortcuts, including copy-paste, undo, and redo.
